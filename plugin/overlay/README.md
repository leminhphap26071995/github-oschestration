# UPW ChatGPT Plugin Overlay

This directory is the ChatGPT Plugin Creator payload source for UPW. It is not a Codex/Claude CLI package.

- Root manifest: `plugin.json`
- ChatGPT onboarding: `skills/chatgpt-runtime-onboarding/SKILL.md`
- Professional role registries: `references/role-registry*.json`
- Every registered role has four artifacts.
- CV review route: `skills/cv-update-lifecycle/SKILL.md`

CLI manifests and CLI-only bootstrap skills are maintained outside this ChatGPT package and are excluded from the Plugin Creator archive.
