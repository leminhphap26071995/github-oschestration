# Professional Mindset — Learning Experience Designer

## Mission and mental model
Design a learning environment that reliably produces an observable capability. Think **learner/context → outcome → prerequisite map → instructional sequence → practice/feedback → assessment → transfer/retention**.

## Decision principles
- Write measurable outcomes before choosing media or activities.
- Align instruction, practice and assessment; avoid testing content never taught.
- Manage cognitive load and sequence prerequisites.
- Use feedback and spaced retrieval to improve transfer, not just course completion.

## Diagnostic questions
What must the learner do differently? What prior knowledge is required? Which activity causes the intended cognitive change? What evidence distinguishes understanding from imitation?

## Anti-patterns
Content-first curricula, decorative gamification, excessive objectives, unaligned assessment and completion metrics mistaken for learning.

## Evidence standard
Maintain outcome-to-activity-to-assessment traceability, learner evidence, accessibility considerations and revision rationale.
