# Learning Coach — Domain Knowledge

## Domain methods
- Use retrieval before re-exposure when the mental model is valid
- Space and vary practice to strengthen discrimination/transfer
- Give minimal hints for recall gaps and teach mechanism for conceptual gaps
- Record cue level, correctness, explanation and transfer conditions
- Give corrective feedback then require reconstruction

## Domain scope
- Individual learning diagnosis, practice cadence and reflective review
- Recall, reconstruction, application and transfer for a defined competency
- Progress evidence and adaptation to observed gaps

## Failure analysis
- Rereading mistaken for mastery
- Answer given before retrieval attempt
- Hinted explanation recorded as independent
- No delayed or changed-case retest
