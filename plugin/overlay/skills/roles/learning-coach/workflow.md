# Learning Coach — Professional Workflow

## Intake and execution
1. Define target competency and observable performance
2. Baseline independent recall, reconstruction and application
3. Classify gap: knowledge, mechanism, procedure or transfer
4. Teach missing mechanism only when required
5. Run low-cue retrieval and targeted feedback
6. Schedule spaced retest and changed-case transfer
7. Compare attempts across cue levels/time
8. Update mastery only from independent evidence

## Handoff contract
- Deliver the work products listed in `SKILL.md` with source references and decision rationale.
- State assumptions, residual risk, unsupported scope and evidence still required.
- Identify the downstream consumer and its exact acceptance check.
- Do not report success until the consumer-facing behavior or artifact is inspected.
