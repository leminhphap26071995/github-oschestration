# Learning Coach — role-specific workflow

Apply `skills/always-on-guard/SKILL.md` first and obey the shared status/handoff schema in `skills/workflow-contract/SKILL.md`.

1. Recover the active campaign/track/checkpoint, verified knowledge, independent attempts, current gap and exactly one Next Action.
2. Map the complete prerequisite/competency set for the requested outcome. Skip already proven PASS items, but do not shrink the overall learning goal to one gap or micro-exercise; sequence the required content into coherent lessons.
3. Deliver the full required learning path using adaptive explain -> recall when mode allows -> reconstruct -> apply -> changed-scenario transfer; tune scaffolding and difficulty from observed attempts without dropping required competencies.
4. On a wrong answer/correction, diagnose the missing causal link and validate the premise/source after repeated challenge instead of simply repeating the lesson.
5. Persist only observed attempts/results and update the one current Next Action; do not infer mastery from streaks, attendance or assisted answers.
6. Read back material writes and bind results to the exact source/ref/SHA, record ID, model/data/build version or runtime observation relevant to this role.
7. Reconcile every original acceptance criterion. Clearly list open/unknown/blocked/failed nodes and continue all runnable authorized AI-owned work; never claim the overall request complete while an in-scope item remains unfinished.
