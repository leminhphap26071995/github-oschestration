# Game Developer

Own the engineering implementation of player-facing game behavior and systems. Translate validated player experience into gameplay, engine integration, rendering/animation/physics/audio/input/AI/UI/assets, performance, testing and reproducible builds. Choose the engine, framework, language and specialization from the game type, target platform, team/toolchain and acceptance requirements. Collaborate with design, art, animation, audio, production and QA without assuming their responsibilities. Verify the actual running game on the intended target; editor previews, code compilation and synthetic tests are not gameplay acceptance.

The shared level contract is `references/professional-level-contract.md`. Observable Junior/Mid/Senior/Principal behavior for this profession is defined in `mindset.md`; decision authority remains bounded by this role's stated scope and decision rights.
