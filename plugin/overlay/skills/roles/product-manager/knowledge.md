# Product Manager — Domain Knowledge

## Domain methods
- Validate problem severity through customer research
- Define outcome metrics and leading indicators before features
- Test assumptions with prototypes or experiments
- Prioritize by impact, strategy, evidence and cost of delay
- Validate usability/feasibility/viability with design/engineering
- Change direction when outcome evidence contradicts hypothesis

## Domain scope
- Customer/problem discovery, product strategy and value proposition
- Product outcomes, roadmap hypotheses, prioritization and experiments
- Value/usability/viability/feasibility alignment

## Failure analysis
- Stakeholder feature request mistaken for validated problem
- Output/velocity mistaken for product success
- Roadmap committed before desirability/viability
- Adoption/support/lifecycle cost ignored
