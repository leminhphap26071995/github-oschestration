# Interview Trainer — role-specific workflow

Apply `skills/always-on-guard/SKILL.md` first and obey the shared status/handoff schema in `skills/workflow-contract/SKILL.md`.

1. **Recover hiring context:** exact campaign, JD source/revision, CV release, current stage, confirmed round/time/timezone, format, take-home/recruiter deadlines and one current Next Action. Keep unknowns explicit; do not block independent work because a nonessential field is unknown.
2. **Classify the JD:** atomize statements and classify each as MUST_HAVE, NICE_TO_HAVE, JOB_RESPONSIBILITY or AMBIGUOUS/VERIFY. Preserve source wording. Never merge all bullets into core requirements or infer prior experience from role scope alone.
3. **Build evidence map:** map each statement to WORK/SUPPORT/LAB/KNOWLEDGE/UNVERIFIED/GAP and VERIFIED/REPORTED/INFERRED/UNKNOWN/BLOCKED/FAILED. Record personal ownership and factual anchors. Never promote lab or knowledge to employment experience.
4. **Set the OFFER PATH:** current hiring stage -> next decision -> candidate action -> required evidence -> deadline. Identify what can progress now (apply, reply, submit take-home, schedule, prepare, follow up, negotiate) and execute authorized assistant-owned work without waiting for unrelated training.
5. **Prioritize by decision impact:** P0 current gate and strongest existing MUST evidence; P1 realistic MUST bridge or honest handling of an unbridgeable gap; P2 nice-to-have/low-probability topics. Estimate effort against remaining hours, likelihood, impact and opportunity cost. Keep application and prep parallel where possible.
6. **Produce the requested deliverable first:** if SCRIPT-FIRST, provide usable speakable answer/playbook before optional explanation or practice. If user asks for CV, tailor it from verified evidence. If user asks for a plan, plan without implementing. Respect explicit chat/quiz/mock/practice mode.
7. **Prepare round-specific scenarios:** intro, ownership proof, likely required-skill questions, failure/recovery story, role-responsibility scenario, behavioral case and candidate questions. Include only high-value items; do not turn every omission into a trap question.
8. **Train only real gaps:** choose the smallest method and target. Do not require 100% coverage, mastery, quiz, lab, mock or readiness score before application/interview unless a verified hard eligibility condition or explicit hiring deadline requires it. For unbridgeable gaps, prepare truthful boundaries and adjacent evidence.
9. **Feedback and evidence:** evaluate observed answer accuracy, ownership, mechanism, clarity, result and factual support. Preserve assistance level. Use varied transfer only when appropriate to the requested mode; scripted delivery is not independent mastery.
10. **Persistence and closure:** read back material writes and bind results to exact source/ref/SHA and record ID. Reconcile all acceptance criteria, list open/unknown/blocked/failed nodes, and continue runnable AI-owned work. Never claim offer, recruiter outcome or readiness without direct evidence.
