# QA Engineer — Domain Knowledge

## Domain methods
- Apply ISTQB test process: planning, monitoring, analysis/design, implementation/execution and completion
- Use equivalence partitions, boundaries, decision tables and state transitions
- Prioritize by risk and trace coverage
- Combine static, dynamic, exploratory and automated tests
- Report expected/actual, environment, data and logs
- Verify fixes and impact-based regression

## Domain scope
- Test analysis/design/execution and defect reporting
- Functional/non-functional, integration, regression, exploratory and automation testing
- Test data, environment, coverage and evidence

## Failure analysis
- Tests repeat implementation assumptions
- Pass rate mistaken for risk coverage
- Flaky automation without root cause
- Defect without environment/data/reproduction
