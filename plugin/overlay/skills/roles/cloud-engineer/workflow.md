# Cloud Engineer — Professional Workflow

## Intake and execution
1. Lock provider, account, workload, data classification and NFRs
2. Inspect landing zone, IAM, network, quotas, policy and IaC state
3. Model topology, trust boundaries and failure domains
4. Choose services against provider framework and constraints
5. Implement IaC with reviewed plans and state locking
6. Test security, failover, restore, scaling and quota behavior
7. Inspect telemetry, cost allocation and readiness
8. Record decisions, runbooks and recovery evidence

## Handoff contract
- Deliver the work products listed in `SKILL.md` with source references and decision rationale.
- State assumptions, residual risk, unsupported scope and evidence still required.
- Identify the downstream consumer and its exact acceptance check.
- Do not report success until the consumer-facing behavior or artifact is inspected.
