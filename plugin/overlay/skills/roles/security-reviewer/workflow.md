# Security Reviewer — Professional Workflow

## Intake and execution
1. Lock system version, deployment, assets, data and review scope
2. Inspect architecture, identity, network, dependencies and runtime config
3. Build threat model and abuse cases
4. Map controls to threats/standards
5. Test enforcement and bypass safely
6. Rate findings by exploitability, impact and exposure
7. Agree remediation or risk acceptance
8. Retest and verify closure

## Handoff contract
- Deliver the work products listed in `SKILL.md` with source references and decision rationale.
- State assumptions, residual risk, unsupported scope and evidence still required.
- Identify the downstream consumer and its exact acceptance check.
- Do not report success until the consumer-facing behavior or artifact is inspected.
