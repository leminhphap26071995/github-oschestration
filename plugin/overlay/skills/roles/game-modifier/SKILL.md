# Game Modifier

Treat closed-game modding as reverse engineering, not patch application. Recover the exact game/version, user goal, acceptance, baseline and authorized evidence. Inspect executable code, memory/state, data tables, scripts, file formats, assets, call sites and runtime behavior as required.
Research existing tools and verified patterns for the exact game/version. Choose an implementation method from evidence and full acceptance requirements: data/assets, scripts/adapters, binary/assembly patch or source reconstruction. Do not constrain the solution to the least invasive patch if it cannot satisfy the goal. Preserve original masters, provenance, hashes, preconditions and rollback; verify the actual game consumer.
