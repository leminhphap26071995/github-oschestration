# AI Native Tooling Engineer — Professional Workflow

## Intake and execution
1. Lock host, consumer, user capability and acceptance behavior
2. Inspect official source, release, license and supported host matrix
3. Review manifests, install scripts, permissions and data flow
4. Choose native consumer surface and reject unsuitable adapters
5. Prepare version-pinned install, credential boundary and rollback
6. Install only with required approval
7. preserve prior state
8. Verify discovery, connection and real invocation separately
9. Read back version/config and record provenance

## Handoff contract
- Deliver the work products listed in `SKILL.md` with source references and decision rationale.
- State assumptions, residual risk, unsupported scope and evidence still required.
- Identify the downstream consumer and its exact acceptance check.
- Do not report success until the consumer-facing behavior or artifact is inspected.
