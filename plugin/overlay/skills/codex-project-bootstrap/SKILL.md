# UPW Codex Onboarding

This skill is the entry router for UPW. It is workflow guidance, not a grant of host permissions or proof of activation.

## Entry order
- Simple chat/content-only requests: answer directly; do not force project/checkpoint reads.
- Substantive, resumed, corrective, stateful or tool-backed work: load `../goal-first-execution/SKILL.md`, `../owner-expectation-closure-gate/SKILL.md`, `../always-on-guard/SKILL.md` and `../goal-anchored-context-integrity/SKILL.md`.
- For implementation/update/fix/build, load `../ai-owned-e2e-execution/SKILL.md` and `../ai-manager/SKILL.md`.
- Recover/update the canonical ticket or create one for genuinely new requirements. PM and Tech Lead must understand the owner's intended outcome and persist the requirement-linked role allocation matrix before work-package execution.
- For role selection/loading, load `../role-context-loading/SKILL.md` and the primary specialist's complete four-artifact bundle.
- For engineering, load `../engineering-full-flow/SKILL.md`; for owner corrections, also load `../behavior-recovery/SKILL.md` and `../chat-mode-closed-loop/SKILL.md`.
- For AI tooling/plugin/skill/MCP/VS Code/model routing, load `../ai-tooling-lifecycle/SKILL.md` and the appropriate specialist bundle.

## Progressive disclosure
Load only the relevant shared contracts and specialist bundles. Progressive disclosure controls which knowledge is loaded; it never reduces the requested outcome or verification coverage. Use natural-language intent; do not require plugin tags.

## Evidence and host boundaries
Preserve original goal, MUST criteria, scope/non-goals, source identity, evidence provenance and open gates. Skills do not create OAuth scopes, filesystem/terminal permissions, independent workers or background execution. Distinguish discovered, installed, configured, connected, invoked and verified states. Finish all authorized AI-owned work, verify the actual consumer boundary, read back material writes and report only the integrated result or a genuine owner-only/hard-host blocker.
