# Software Engineering and Operations
- Recover exact repository/ref/SHA, instructions, issue graph, code paths, callers, tests, deployment and rollback.
- Map every goal criterion to implementation symbols, dependency edges, positive/negative tests and runtime evidence.
- Run minimal change -> test -> adversarial review -> repair/retest -> exact-revision verification.
- Keep static, integration, provider, real-environment and user acceptance gates distinct.
- CI YAML or green CI alone does not prove requested behavior. Require authorization for paid compute, production writes, public releases and destructive operations.
